# 🧬 Biofísica 
Aplicación web de **práctica activa de Biofísica** basada en preguntas organizadas por módulos.

La idea no es solamente responder preguntas, sino usar los resultados para detectar qué temas necesitan repaso y orientar mejor el estudio.

### 🚀 [Abrir la aplicación](https://ro-fer.github.io/Biofisica/)

---

## 🧠 ¿Qué podés hacer?

* Practicar preguntas de Biofísica organizadas por módulo.
* Corregir cada respuesta y recibir feedback.
* Ver tu progreso durante el cuestionario.
* Registrar resultados de cada módulo.
* Repetir las preguntas respondidas incorrectamente.
* Identificar temas que conviene volver a estudiar.
* Reiniciar el progreso cuando quieras.

El progreso se guarda localmente en el navegador.

---

## 📚 Módulos

### 01 · Metabolismo celular e interacción ligando–receptor

Incluye temas como:

* biomoléculas;
* sustancias polares y anfipáticas;
* cinética enzimática;
* Michaelis–Menten;
* interacción ligando–receptor.

### 02 · Compartimientos biológicos y transporte

Incluye:

* compartimientos líquidos;
* osmolaridad;
* transporte a través de membranas;
* difusión facilitada;
* transportadores como GLUT;
* cambios de volumen celular.

### 03 · Equilibrios iónicos

Incluye:

* ecuación de Nernst;
* potenciales de equilibrio;
* fuerza impulsora;
* potencial de membrana;
* permeabilidad iónica;
* equilibrio de Donnan.

## 🎯 Enfoque

Este proyecto está pensado como una herramienta complementaria de estudio.

La lógica es simple:

**practicar → equivocarse → detectar patrones → repasar → volver a intentar**

En lugar de usar el cuestionario solamente para obtener un puntaje, los resultados sirven para decidir **qué estudiar después**.

---

📊 Seguimiento del estudio

La aplicación utiliza los resultados para mostrar una hoja de ruta orientativa con temas que podría ser útil revisar.

🧪 Función en pruebas: el sistema de seguimiento y recomendaciones todavía está en desarrollo y puede no interpretar correctamente todos los resultados o situaciones de estudio.

Por ahora, esta función debe tomarse como una ayuda complementaria y no como una evaluación definitiva del desempeño.

Actualmente, el contenido está organizado en tres módulos y se complementa con información de desempeño y prioridades de repaso.
---

## 🗂️ Estructura del proyecto

Las preguntas y datos de estudio se mantienen separados de la interfaz para facilitar la actualización y ampliación del banco.
